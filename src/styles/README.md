# Styles Directory

This directory contains global CSS files and style utilities beyond Tailwind CSS.

## Structure
- Global CSS overrides
- Custom component styles (if needed)
- Theme-specific styles
- Print styles
- Animation definitions

Most styling will be handled by Tailwind CSS, but this directory is available for:
- Complex animations that require CSS keyframes
- Global style resets or overrides
- Third-party library style customizations
- Print-specific styles
